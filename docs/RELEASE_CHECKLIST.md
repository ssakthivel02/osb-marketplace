# Marketplace Release Checklist

- [ ] CI policy and negative tests pass
- [ ] API contract is versioned
- [ ] Tenant isolation and RBAC tests pass
- [ ] Seller verification is enforced
- [ ] Prices, currency, tax and discounts are server-authoritative
- [ ] Order and refund idempotency tests pass
- [ ] Payment provider tokenisation is confirmed
- [ ] Signed webhook and replay tests pass
- [ ] Settlement, refund and chargeback reconciliation passes
- [ ] Guardian approval works for minor accounts
- [ ] English and Tamil journeys are reviewed
- [ ] Accessibility, load and failure tests pass
- [ ] Dashboards, alerts, backup, restore and rollback evidence are attached

Release remains NO-GO while any mandatory item is incomplete.
