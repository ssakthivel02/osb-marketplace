# Marketplace Quality Evaluation

A release is acceptable only when evidence demonstrates:

- Authentication, authorisation and tenant isolation
- Server-authoritative price, tax, discount and currency calculation
- Immutable order snapshots and idempotent purchase/refund processing
- Verified sellers and governed listing publication
- Provider tokenisation; no raw card storage
- Signed webhook verification and replay protection
- Guardian approval for minor purchases
- Accessible English and Tamil purchase, refund and support journeys
- Rate limiting, fraud monitoring, reconciliation and auditability
- Backup, restore, rollback and incident-response tests

Passing policy validation is necessary but not sufficient for production approval.
